# Kindora (CommuniFlow)

Платформа для управління волонтерськими проєктами, побудована на React. Kindora допомагає командам знаходити, приєднуватися до соціальних та громадських ініціатив і керувати ними — все в одному місці. Учасники можуть відстежувати прогрес, співпрацювати над місцевими проєктами та залишатися організованими.

Застосунок підтримує дві ролі: звичайні **учасники**, які можуть переглядати проєкти та долучатися до них, та **адміністратори**, які керують чергою проєктів, розглядають заявки та здійснюють нагляд за спільнотою.
